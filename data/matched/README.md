# Matched Datasets for Controlled Cross-Lingual Comparison

## Overview

These datasets have been created through stratified sampling to ensure:
- Identical sample sizes across all languages
- Standard 70/15/15 train/val/test split
- Matched class distributions

## Statistics

- Total samples per dataset: 22,152
- Train: 15,506 (70%)
- Validation: 3,323 (15%)
- Test: 3,323 (15%)

## Datasets

1. Native Hausa: `data/matched/hausa/`
2. Native English: `data/matched/english/`
3. Translated Hausa: `data/matched/english_translated_hausa/`

## Methodology

Stratified random sampling with seed=42 for reproducibility.
